# 本地陪伴模式

点击人物气泡里的“陪伴”，或人物右键 / 托盘的“陪伴模式 / 控制面板”，再点“开启陪伴”。也可用“打开陪伴控制”快捷方式进入面板。每次启动默认关闭，程序不会自行恢复上次的软件识别。

识别只读取当前前台程序的进程名称，在本机归类为浏览器、绘画、工作、音乐、游戏或其他软件。不读取窗口标题、网页正文、画面、音频、剪贴板或输入文字，不上传截图，不调用 API。仅当绘画软件位于前台、且撤回检测选项开启时，额外采样 Ctrl+Z 的按下状态。没有通用键盘记录。关闭陪伴会结束识别辅助进程；进入猫猫、切换角色、暂时隐藏人物或退出也会停止。

- 不操作按钮时，每十分钟尝试从当前软件类型的固定台词组随机选一条，可在一条中写 1～3 句。无法识别到前台、正在聊天、正在摸头或处于冷却时跳过，不补发积压消息。
- 点“吐槽一下”立即按最近识别的软件类型选择台词。点控制面板后，会短暂保留此前的软件分类，避免把桌宠自己误认为用户正在做的事。
- 已识别的绘画软件中，8 秒内至少四次 Ctrl+Z 触发一次撤回反馈；点击软件的撤回工具栏或其他快捷键目前不算，按住不放也只算一次。
- 游戏死亡不自动识别。“我又翻车了”按钮是用户主动报告，不代表角色看见了死亡画面。
- 默认所有触发共用 60 秒冷却、每日 30 次上限；可设 30～600 秒和每日 1～100 次。预算按电脑本地日期重置，关闭 / 重开陪伴或重启程序不重置当天计数。token 使用始终为零。
- 吐槽使用单独气泡显示约 18 秒后收起，不打开输入框、不抢键盘焦点、不写进聊天或长期记忆。固定表情可配合台词，手动锁定表情优先。
- 关闭陪伴面板窗口只收起控制面板。要停止识别，请点面板的“关闭陪伴 · 停止识别”或托盘中的同名菜单。此时仍可正常手动聊天。

固定台词、共用冷却、次数上限和选项保存在 `%APPDATA%\KairosDesktop\companion.json`，不包含当前软件名称或按键时间序列。最近的软件分类、短时撤回计数和最后一句吐槽只在内存里使用，不作为活动日志保存。不要把运行数据文件提交到公开仓库。

支持常见的 Edge、Chrome、Firefox、Photoshop、Aseprite、Krita、Clip Studio Paint、SAI、Blender、Office、VS Code、Spotify 等程序。无法识别的游戏可勾选“将无法识别的软件按游戏陪伴”；已识别浏览器等仍用自身分类。单凭软件类型不能知道正在看的网页、画的内容或游戏胜负，所以台词应保持宽泛。世界书与人设不会自动改写这些本地台词，可以在控制面板逐类修改。

Windows 识别使用 [GetForegroundWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getforegroundwindow)、[GetWindowThreadProcessId](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getwindowthreadprocessid) 和 [GetAsyncKeyState](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getasynckeystate)。受系统桌面访问权限、应用权限和输入方式限制，可能无法识别部分程序或撤回操作；不会申请管理员权限或修改系统保护。辅助进程由应用启动和结束，不安装系统服务、不创建开机启动。
