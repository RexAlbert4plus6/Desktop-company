# 猫猫本地试用 DLC

在程序旁放置 `dlc/kairos-cat/`，包含以下九张透明 PNG；素材不随公开代码发布。当前仅为 1 号 Kairos 槽位启用。

- `Kairos kitty1.png`：正面坐姿。
- `Kairos kitty9.png`：背面坐姿。
- `Kairos kitty walk7.png`、`Kairos kitty walk8.png`：侧面坐姿。
- `Kairos kitty walk2.png`、`Kairos kitty walk3.png`、`Kairos kitty walk4.png`：朝左站立与迈步。
- `Kairos kitty walk5.png`、`Kairos kitty walk6.png`：朝右迈步与站立。

当前素材均为 82×82，程序按每帧的身体中心与脚底对齐，不修改原图。画布使用关闭平滑的 2 倍整数像素绘制，并补偿 Windows 显示缩放。猫身体实际约 70～122×110 像素；不能由低分辨率图片恢复未画出的细节。想画更精细的版本，建议以后统一使用 164×164 画布重新绘制，保持相同脚底位置；本版专用于现有 82×82 包，不是任意尺寸导入器。

点击人物气泡菜单中的“猫猫”，或从人物右键 / 托盘菜单选择“猫猫试用（本地 DLC）”。开始时收起人物、气泡与设置窗口。猫猫在人物所在显示器的任务栏上沿活动：随机坐 18～45 秒，然后走 1.6～3.8 秒，到边缘也会停下来。偶尔换坐姿看向前方、侧面或桌面。约九成时间保持坐姿。Windows 任务栏设置在侧边或顶部时，本版仍沿可用桌面的底部活动。

点击猫猫会变回人物并打开原来的聊天气泡，不插入新问候。聊天记录、输入草稿、人设、记忆、手动表情和饰品都沿用原状态。猫猫不会说话、调用 API、读取屏幕或写入聊天记忆。每次重新启动默认显示人物。

任务栏自动隐藏时，猫猫沿当前系统报告的可用桌面底边活动。显示器断开 / 分辨率或缩放改变会重新约束活动范围。猫猫暂不支持拖动、道具、睡觉或全身动作，这些可在试用后继续扩展。

完整退出桌宠后，移走程序旁的 `dlc/kairos-cat` 文件夹即可停用这份素材包，人物功能仍可使用。
