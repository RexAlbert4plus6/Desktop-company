DeepSeek：登录 platform.deepseek.com，在 API keys 页面创建密钥并复制到上方。OpenRouter：登录 openrouter.ai，在 Keys 页面创建密钥。不要把密钥发到聊天或上传 GitHub。余额页面的地址不是密钥。
