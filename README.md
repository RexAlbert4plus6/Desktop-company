## 使用

运行打包文件夹里的 `Desktop-company.exe`，不需要另外安装 Node.js。

1. 点击角色打开气泡，在设置中选择 DeepSeek 或 OpenRouter。
2. 粘贴自己的 API 密钥，填写模型名，点击“保存并测试连接”。DeepSeek 地址和默认模型已填好。
3. 返回桌面，点击角色展开 / 收起输入框。Enter 发送，Shift + Enter 换行。
4. 右键人物或使用托盘菜单，可以打开完整记录、设置、隐藏或退出。

密钥在服务商后台创建：[DeepSeek](https://platform.deepseek.com/api_keys)、[OpenRouter](https://openrouter.ai/settings/keys)。连接测试发送一个短请求，可能产生少量 API 费用。

## 摸头与饰品

- **摸头：不按鼠标键，在头顶左右来回划几下。** 慢划是轻柔摸头，快速来回是粗鲁摸头。过程中显示 smile，停下后随机显示对应台词与表情。粗鲁摸头有合计约 1% 的稀有反应。
- 按住鼠标拖动人物仍是移动，不会识别成摸头。
- 在气泡菜单栏点“饰品”，猫耳、围巾、毛衣可以独立佩戴、组合和取下。佩戴时显示一条固定随机台词。
- 摸头和饰品反馈完全本地运行，不调用 AI、不消耗 token。当前没有语音朗读。

## 角色与素材包

设置中提供四个角色槽位。选择槽位后，将 PNG 拖到 Normal、Blink、Happy、Unhappy、Angry、Smile、Surprised 等格子，或点击格子选择文件。半闭眼及其他表情可选。

每个角色的名字、人设、图片、饰品、聊天和长期记忆独立保存。切换 / 修改人设会保留共享的世界书、用户信息和 API 设置。切换前保存当前表单，API 请求进行时不能切换。

“打开 character 文件夹”打开当前槽位的实际素材存储；程序旁也有 `character` 文件夹可保存导出的包。导出只含人设与图片，不含密钥、聊天、记忆、世界书或用户信息。详细格式见 [角色素材包说明](docs/character-pack.md)。

## 表情、眨眼与问候

Normal 随机约每 3–6 秒眨眼，偶尔双眨。非 Normal 表情暂停眨眼。聊天模型在同一次回复末尾选择一个表情编号，程序去掉编号再显示台词，不增加独立判断请求。自动表情最多持续 5 秒，新回复可以提前切换。

点击“切换表情”打开预览轮盘。手动选择非 Normal 后会保持，即使重启也不自动覆盖；选 Normal 恢复自动模式。摸头可临时覆盖表情，结束后恢复原先锁定状态。

固定问候按电脑本地时间选组：05:00–08:00、11:30–13:00、22:00–00:00 使用对应组，其他时间使用 Random 组。默认冷却 15 分钟，可调为 10～20 分钟；连续聊天时不插入问候。没有无人点击时的定时弹出。

## 本地数据与记忆

数据位于 `%APPDATA%\KairosDesktop`，可从设置打开或导出备份。更新程序继续使用这个目录，不要只复制旧安装目录来备份数据。

完整记录留在本地。普通聊天向所选 API 提供角色设定、世界书、用户填写的信息、长期记忆，以及近期最多 40 条、约 32000 字历史。世界书目前是纯文本全文读取。

“总结记忆”会使用当前 API，按批提炼尚未总结的新对话、合并并保存长期记忆。总结前保留旧记忆备份，重复点击不会重新处理已覆盖的记录。总结有 API 成本，结果可手动修正。

API 密钥使用 Windows 的保护机制加密保存；聊天文本未加密。`.gitignore` 和公开源码打包白名单排除私人素材、角色包、运行数据、密钥、安装包及快捷方式。请不要把自己的运行数据目录或私人素材包上传到公开仓库。

## 置顶与当前限制

可开启置顶，程序会提高窗口层级并维护可见窗口状态，不抢键盘焦点。普通桌面为主要目标；独占全屏游戏、系统安全桌面及其他特殊窗口不保证覆盖。

当前猫猫是可选的本地试用模式；陪伴模式可手动开启前台软件类型识别与固定吐槽，没有截图内容理解、游戏死亡自动识别、多人同屏或自动 AI 对话。模型回复一次性显示，失败时输入保留，可重试。

## 开发与打包

使用 Node.js 22 和 Windows x64：

```sh
npm ci
npm test
npm start
npm run package
```

输出位于 `dist/v0.9.0/Desktop-company-win32-x64`。请保留整个文件夹，不要单独移动 exe。公开构建使用占位图，可在设置中导入自己的角色。仓库包含 GitHub Actions Windows 构建配置。

`npm run source` 按白名单生成 `release/source` 和哈希清单，供审查与发布。原型暂未提供代码签名或自动更新。
