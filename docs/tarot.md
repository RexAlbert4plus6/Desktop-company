# Samuel · Draw A Card

切换到 Samuel 后，在桌面气泡的「饰品」中选择 **Draw A Card**。可以输入一个不超过 300 字的问题，也可以留空抽今日牌；点击三张牌背中的一张后，由 Samuel 解读。

本地从完整的韦特体系 78 张牌中随机发出三张不同的牌，正位 / 逆位各 50%。选牌前不调用 API，也不把隐藏的三张牌传给界面。选定后只请求一次当前配置的 API；双击不会重复请求。单次输出上限 420 token，输入只含 Samuel 的主要人设、选中的牌及问题，不带聊天历史、长期记忆、世界书、用户资料或其他角色的关系背景。实际费用还包含输入 token。

解读失败或关闭窗口会保留本轮选择，重试同一张牌会发起新请求并可能产生费用。关闭正在解读的窗口会取消等待，但服务商已开始的计算仍可能计费。已成功的结果重新打开时直接展示，不重复请求；每轮新发牌至少间隔 10 秒。解读不写入普通聊天或长期记忆，退出程序后不保留抽牌结果。

解读期间禁止切换角色或修改设置；切换角色后关闭并清除本轮卡牌。当前玩法属于 `interactionProfile: "samuel"` 的角色卡，不会出现在 Kairos 槽位。

自定义牌背放在对应角色素材包的 `assets/tarot-back.png`，可随角色素材包导入 / 导出；未提供时使用公开版内置的简单占位牌背。私人画作只保存在本机，不包含于 GitHub 仓库。当前所有牌面均显示牌背并标注英文牌名和正逆位，等待后续牌面素材。

牌组含 22 张大阿尔卡那与四组各 14 张的小阿尔卡那，Strength 为 VIII、Justice 为 XI。参考 A. E. Waite 原书 [The Pictorial Key to the Tarot](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot)。
